# Clicker Game — *Hity Polskiego Internetu*

A browser-based incremental clicker / idle game themed around iconic Polish internet memes. Click your way through Polish internet history, collect meme upgrades, and automate your meme production empire.

## Overview

*Hity Polskiego Internetu* is a clicker/idle game built as a university project. The gameplay loop is simple: click to generate "hity" (hits), spend them on upgrades and auto-clickers, and watch your meme factory scale up automatically. All progress is saved locally so you can pick up where you left off.

## Features

- Click-based resource generation themed around Polish internet memes
- Upgrade system with multiple tiers and compounding multipliers
- Auto-clicker buildings that produce resources passively
- Offline progress calculation on return
- Persistent save / load via `localStorage`
- Responsive UI — playable on desktop and mobile

## Tech Stack

| Layer | Technology |
|-------|-----------|
| UI | HTML5 + CSS3 |
| Logic | Vanilla JavaScript |
| Persistence | `localStorage` |

## Getting Started

```bash
git clone https://github.com/PrzemyslawSalek/clicker_game.git
cd clicker_game
open index.html   # or just double-click index.html in your file manager
```

No build step required — runs directly in any modern browser.
